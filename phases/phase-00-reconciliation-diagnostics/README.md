## Purpose

Establish the real starting line before prescribing Phase 1.

Phase 0 reconciles useful prior Week 2 structured-output/reliability work, measures current Python, math, LLM, interview, debugging, code-reading, and project-ownership capability, and initializes the control evidence required to prescribe Phase 1 from observed evidence rather than assumption.

Phase 0 is diagnostic. It is not a disguised broad study phase.

## Max Five Requirements

1. Reconcile relevant prior Week 2 work with a deliberate `FINISH`, `REUSE`, `FREEZE`, `DEFER`, or `KILL` state.
2. Establish the Python baseline across language, DSA, engineering, debugging, and code reading.
3. Establish the lightweight math + LLM baseline and determine later primer depth.
4. Establish interview + project-ownership baseline through representative bounded exercises.
5. Initialize readiness, gap, resource/certification, and phase-state evidence.

## Diagnostic Integrity

HARD:

- Do not study an answer before its baseline is captured.
- Do not repair a failed diagnostic and count the repaired attempt as the baseline.
- Do not infer mastery from old project existence alone.
- Distinguish observed capability, credible prior evidence, and unassessed capability.
- Record misses; a miss is useful placement evidence.
